# Contribute Page Flow Diagram

```text
Student paper metadata
        |
        v
ka_contribute_public.html form
        |
        v
classifier request payload
        |
        v
classifier / endpoint contract
        |
        v
visible result verdict on page
        |
        v
stored contribution record for review
```

The original failure mode was a missing visible result path: a student could submit a paper without receiving an interpretable classifier verdict.
